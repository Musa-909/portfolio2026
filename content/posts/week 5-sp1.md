# SP-1 Movie Repository

Et gruppeprojekt hvor vi udviklede en backend applikation, der henter filmdata fra TMDb API og gemmer dem i en PostgreSQL database.

## Development Log

### Week 5 – SP-1 Movie Repository

I uge 5 arbejdede vi med vores første større gruppeprojekt, SP-1 Movie Repository.

Formålet med projektet var at udvikle en backend applikation, der kunne hente filmdata fra TMDb API og gemme oplysningerne i vores egen PostgreSQL database.

Vi arbejdede med film, skuespillere, instruktører og genrer. Ved hjælp af JPA og Hibernate oprettede vi entities og relationer mellem de forskellige data.

Min primære opgave i gruppen var at arbejde med DTO-klasserne, som blev brugt til at håndtere data fra det eksterne API.

Vi arbejdede også med DAO- og serviceklasser for at holde projektets struktur overskuelig.

## Det har vi arbejdet med

- Arbejdet med TMDb API
- Hentet filmdata fra et eksternt REST API
- Arbejdet med JSON og DTO'er
- Oprettet MovieDTO
- Oprettet MovieResponseDTO
- Oprettet GenreResponseDTO
- Arbejdet med JPA og Hibernate
- Oprettet entities og relationer
- Gemt filmdata i PostgreSQL
- Arbejdet med DAO- og serviceklasser
- Arbejdet med JUnit og Testcontainers
- Testet forskellige funktioner i vores backend
- Forberedt en kort præsentation af projektet

## Resultat

Ved afslutningen af SP-1 havde vi udviklet en backend applikation, der kunne hente filmdata fra TMDb API og gemme dem i vores egen database.

Systemet kunne blandt andet arbejde med film, skuespillere, instruktører og genrer samt søge efter film og vise forskellige oplysninger.

Vi fik samtidig erfaring med at kombinere flere af de teknologier, vi tidligere havde arbejdet med, herunder REST API, DTO'er, JPA, Hibernate og PostgreSQL.

Min opgave med DTO-klasserne gav mig en bedre forståelse for, hvordan JSON-data fra et eksternt API kan omdannes til Java-objekter.

Projektet gav os mulighed for at bruge vores viden i praksis og arbejde sammen om en større backend applikation.
