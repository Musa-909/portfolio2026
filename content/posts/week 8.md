# Driving School Management System

Et portfolio projekt hvor vi gennem semesteret udvikler et backend system til administration af en køreskole.

## Development Log

### Week 8 – Deployment

I uge 8 arbejdede vi med deployment og DevOps, hvor fokus var på at lære, hvordan en Java applikation kan køres på en server i stedet for kun lokalt.

Vi blev introduceret til Docker, Docker Hub, Docker Compose, GitHub Actions og CI/CD.

Formålet var at forstå, hvordan man kan pakke en applikation i en container og gøre den tilgængelig på en server.

Vi lærte også, hvordan GitHub Actions kan bruges til at automatisere forskellige processer i forbindelse med build og deployment.

I vores Driving School Management System arbejdede vi videre med deployment af vores backend, så applikationen kan køre uden for vores lokale udviklingsmiljø.

## Det har vi arbejdet med

- Lært om deployment og DevOps
- Arbejdet med Docker og Docker containers
- Lært om Docker Hub
- Arbejdet med Dockerfile
- Arbejdet med Docker Compose
- Lært om GitHub Actions
- Arbejdet med CI/CD
- Brugt Maven til at bygge vores Java applikation
- Arbejdet med JAR-filer
- Arbejdet med deployment af DriveApp
- Arbejdet med PostgreSQL i forbindelse med deployment
- Lært om forskellen mellem lokal udvikling og produktion

## Resultat

Ved slutningen af uge 8 havde vi fået en bedre forståelse for, hvordan deployment fungerer, og hvordan man kan gøre en backend applikation tilgængelig uden for sit lokale udviklingsmiljø.

I vores Driving School Management System arbejdede vi med Docker og deployment, så vores Java applikation kan køre på en server.

Vi fik samtidig erfaring med GitHub Actions og CI/CD, som kan bruges til at automatisere build og deployment.

Arbejdet gav os en bedre forståelse for, hvordan en applikation går fra udvikling til drift, og hvordan Docker kan gøre det nemmere at håndtere applikationer på forskellige miljøer.

Samlet set har vi nu arbejdet med de vigtigste backend emner gennem semesteret, herunder JPA, Hibernate, REST API, testing, security og deployment.
