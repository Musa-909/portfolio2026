# Driving School Management System

Et portfolio projekt hvor vi gennem semesteret udvikler et backend system til administration af en køreskole.

## Development Log

### Week 6 – REST Testing

I uge 6 arbejdede vi videre med REST API'er, hvor fokus var på at lære, hvordan man tester endpoints automatisk.

Vi arbejdede med REST Assured og Hamcrest, som bruges til at teste REST API'er og kontrollere, om de returnerer de forventede resultater.

Vi lærte, hvordan man kan teste forskellige HTTP-metoder som GET, POST, PUT og DELETE samt kontrollere HTTP-statuskoder og data i responses.

Vi arbejdede også med at kontrollere bestemte værdier i response body, så vi kunne sikre, at API'et returnerede de korrekte oplysninger.

Derudover blev vi introduceret til WebSockets, som gør det muligt at have kommunikation i realtid mellem en server og flere klienter.

## Det har vi arbejdet med

- Arbejdet med automatiseret REST API-testing
- Lært om REST Assured
- Arbejdet med Hamcrest
- Testet GET, POST, PUT og DELETE requests
- Kontrolleret HTTP-statuskoder
- Arbejdet med response body
- Testet forskellige værdier i API responses
- Lært om automatiserede tests frem for manuel testing
- Arbejdet med WebSockets
- Lært om realtidskommunikation mellem server og klient
- Arbejdet med en Dice WebSocket-øvelse

## Resultat

Ved slutningen af uge 6 havde vi fået en bedre forståelse for, hvordan man tester REST API'er automatisk ved hjælp af REST Assured og Hamcrest.

Vi lærte, hvordan vi kan kontrollere, om vores endpoints returnerer de korrekte statuskoder og data, og hvordan automatiserede tests kan gøre udviklingen mere effektiv.

Vi fik samtidig en introduktion til WebSockets og arbejdede med en Dice WebSocket-øvelse, hvor flere klienter kunne kommunikere med den samme server og modtage resultater i realtid.

Samlet set gav ugen os en bedre forståelse for REST API-testing og realtidskommunikation, som vi kan bruge i vores fremtidige backend projekter.
