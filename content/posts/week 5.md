# Driving School Management System

Et portfolio projekt hvor vi gennem semesteret udvikler et backend system til administration af en køreskole.

## Development Log

### Week 5 – REST API

I uge 5 arbejdede vi med REST API'er og lærte, hvordan man opretter endpoints i Java ved hjælp af Javalin.

Formålet var at forstå, hvordan en backend applikation kan modtage HTTP requests og sende responses tilbage til klienten.

Vi arbejdede med HTTP-metoderne GET, POST, PUT og DELETE, som bruges til at hente, oprette, opdatere og slette data.

Vi lærte også om HTTP-statuskoder, og hvordan et API skal håndtere forskellige requests og fejl.

Som en del af undervisningen arbejdede vi med en Dog API-øvelse, hvor vi oprettede endpoints til at håndtere oplysninger om hunde.

Efterfølgende arbejdede vi videre på vores Driving School Management System, hvor vi implementerede REST API-funktionalitet til administration af elever.

## Det har vi arbejdet med

- Lært om REST API og HTTP
- Arbejdet med Javalin
- Arbejdet med GET, POST, PUT og DELETE
- Lært om HTTP-statuskoder
- Arbejdet med URI'er og endpoints
- Oprettet en Dog API som øvelse
- Arbejdet med DTO'er til requests og responses
- Oprettet StudentRequestDTO og StudentResponseDTO
- Arbejdet med controllers og routes
- Oprettet StudentController
- Implementeret CRUD endpoints til elever
- Arbejdet med fejlhåndtering
- Dokumenteret vores REST API i README

## Resultat

Ved slutningen af uge 5 havde vi fået en bedre forståelse for, hvordan REST API'er fungerer, og hvordan man udvikler endpoints med Javalin.

I vores Driving School Management System implementerede vi REST API-funktionalitet, så systemet kan håndtere oplysninger om elever gennem forskellige HTTP requests.

Vi oprettede endpoints til at hente alle elever, hente en bestemt elev, oprette nye elever, opdatere oplysninger og slette elever.

Ved hjælp af controllers, routes og DTO'er fik vi en mere struktureret backend, hvor de forskellige dele af applikationen har deres egne ansvarsområder.

Vi arbejdede samtidig med dokumentation af vores endpoints i README, så det er nemmere at forstå, hvordan API'et skal bruges.

Det gav os et godt fundament for at arbejde videre med REST API-testing og sikkerhed i de kommende uger.
